# 사자사자 가계부 MVP PRD (v1.0)

작성일: 2026-02-26
기준 문서: `/PRD.md`

---

## 1. MVP 목표

### 1.1 제품 목표
- 부모-자녀 관계 기반으로 자녀 금융 활동(자산/거래/목표)을 기록하고 추적할 수 있게 한다.
- 자녀의 저축 목표 달성 경험을 강화한다.

### 1.2 성공 조건 (MVP Exit Criteria)
- 인증된 사용자 기준 핵심 API 정상 동작
- 주요 시나리오 테스트 통과
- 운영 배포 가능한 최소 보안/검증 충족

---

## 2. MVP 범위

## 2.1 포함 (In Scope)
- 회원가입/API 로그인/JWT 로그아웃
- 이메일 인증 상태 기반 로그인 차단
- 자산 CRUD (소프트 삭제 포함)
- 거래 CRUD
- 정기지출 CRUD
- 미션 생성/조회/수정/삭제/완료/포기
- 명언 랜덤 조회, 명언 스크랩 CRUD
- Swagger 문서 노출

## 2.2 제외 (Out of Scope)
- 오픈뱅킹 실연동
- AI 피드백 자동 생성
- 푸시/알림
- 리포트/통계 대시보드 고도화
- 다국어/다지역화

## 3. 핵심 사용자 시나리오

### US-001 자녀 금융 기록
- 자녀는 자산을 등록하고 거래를 기록한다.
- 완료 기준: 자산/거래 CRUD 성공, 타인 데이터 접근 차단.

### US-002 부모 모니터링
- 부모는 본인 + 자녀 거래 내역을 조회한다.
- 완료 기준: 조회 허용, 수정/삭제 불가 규칙이 지켜짐.

### US-003 목표 저축 미션
- 자녀는 미션 목표를 만들고 완료/포기 처리한다.
- 완료 기준: 진행중 목표 1개 제한, 스냅샷 고정.

### US-004 콘텐츠 참여
- 사용자(인증)는 금융 명언을 스크랩하고 관리한다.
- 완료 기준: 사용자 기준 중복 스크랩 방지.

## 4. 기능별 MVP 요구사항

## 4.1 Auth/Users
- 이메일 인증 전 로그인 불가
- JWT access/refresh 발급
- 로그아웃 시 refresh blacklist 처리

## 4.2 Assets
- `asset_type`: `bank/card/cash/giftcard`
- `balance >= 0`
- 소프트 삭제(`is_active=false`)

## 4.3 Finance
- 거래: 작성자 본인만 수정/삭제
- 부모는 자녀 거래 조회 가능
- 정기지출: 사용자별 데이터 분리

## 4.4 Missions
- 목표금액 최소 1원
- 마감일 오늘 이상
- 진행중 목표 1개 제한
- 완료/포기 시 snapshot 및 완료시각 고정 저장

## 4.5 Contents
- 랜덤 명언 조회
- `(user, proverb)` 중복 스크랩 금지

## 5. 수용 기준 (MVP Acceptance)

### AC-01 인증
- 미인증 로그인: 403
- 인증 완료 로그인: 200 + 토큰

### AC-02 접근 제어
- 비로그인 보호 엔드포인트 접근: 401
- 타인 데이터 접근/수정 시 차단

### AC-03 도메인 제약
- 자산 음수 잔액 저장 불가
- 미션 중복 진행중 생성 불가
- 명언 중복 스크랩 불가

### AC-04 테스트
- `manage.py test` 전체 통과
"""
- Ran 65 tests in 16.053s

OK
"""

## 6. 릴리스 체크리스트

### 6.1 환경/설정
- `SECRET_KEY`, DB, EMAIL 환경변수 적용
- 운영 도메인 인증 링크 설정 확인

### 6.2 데이터/마이그레이션
- 최신 마이그레이션 반영
- 초기 데이터(명언) 시드 여부 확인

### 6.3 보안/권한
- 소유권 우회 불가 검증
- 민감정보(`encrypted_number`) 암호화 저장 확인

### 6.4 문서
- Swagger 엔드포인트 확인
- API 사용 가이드 업데이트
